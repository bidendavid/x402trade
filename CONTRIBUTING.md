# Contributing to x402Trade

Thank you for your interest in x402Trade!

## Current Status

x402Trade is in active early development. We are **not accepting external Pull Requests** at this time while we stabilize the core platform.

## How You Can Help

### Report Bugs
Open an [Issue](https://github.com/bidendavid/x402trade/issues/new?template=bug_report.md) with:
- What you did
- What you expected
- What actually happened
- Relevant logs or screenshots

### Suggest Features
Open an [Issue](https://github.com/bidendavid/x402trade/issues/new?template=feature_request.md) describing the use case and why it would be valuable for AI agent developers.

### Ask Questions
Use [GitHub Discussions](https://github.com/bidendavid/x402trade/discussions) for questions about integration, the x402 protocol, or how the exchange works.

## Future Contributions

We plan to open the project to external contributions once the platform is live and stable. Watch the repo to be notified when that changes.

## Security Issues

**Do not open public Issues for security vulnerabilities.**
Contact us privately at security@getx402.trade before disclosing publicly.
